## Operational boundaries after implementation

The historical checkpoints above are superseded by the final acceptance section.
Personal customization still requires explicit app-owned copy/export/review before
selection. Never migrate real settings or regenerate existing cases merely to
activate this feature. Existing cases remain legacy or pinned; new defaults are
creation-only. Further live-model quality evaluation or private-record testing
requires separate authorization and does not follow from these synthetic results.
